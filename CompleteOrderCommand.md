Завершить заказ (Complete Order)

Курьер может завершить заказ, если он рядом с точкой доставки заказа.



Поля Command:

courierId UUID
orderId UUID
Сценарий Command Handler:

Получить курьера из БД
Получить заказ из БД
Завершить выполнение Assignment для курьера
Пометить заказ как завершенный
Сохранить все изменения в БД
